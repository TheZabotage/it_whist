## 2. Database Schema

```
Account
  id, name, nickname, email, hashed_password, is_admin
  confirmed_at, inserted_at, updated_at

Game
  id, status (in_progress/completed), played_at
  created_by FK → accounts

GamePlayer
  id (surrogate PK), game_id FK, player_id FK
  final_score, inserted_at, updated_at
  UNIQUE (game_id, player_id)

Round
  id, game_id FK, game_type (string), round_number
  inserted_at, updated_at
  UNIQUE (game_id, round_number)

Bet
  id, round_id FK, game_player_id FK
  game_player_partner_id FK (nullable)
  sets_bid, sets_won (nullable), partner_ace (nullable)
  inserted_at, updated_at

RoundScore
  PK (round_id FK, game_player_id FK)
  score, inserted_at, updated_at
```

## 3. Permission Tiers

```
Public          → view leaderboards, stats, game history
Authenticated   → all of above + log games, add rounds/bets
Admin           → all of above + create accounts
```

Router groups:
```elixir
# Public
live_session :public,
  on_mount: [{ItWhistWeb.AccountAuth, :mount_current_scope}] do
  live "/", LeaderboardLive.Index, :index

# Authenticated
live_session :require_authenticated,
  on_mount: [{ItWhistWeb.AccountAuth, :require_authenticated}] do
  live "/games/new", GameLive.Form, :new

# Admin
live_session :require_admin,
  on_mount: [{ItWhistWeb.AccountAuth, :require_admin}] do
  live "/admin/accounts/new", AccountLive.Registration, :new
```

## 4. Auth System

Generated by `mix phx.gen.auth`. Supports magic link + password login.

**Key modules:**
- `AccountAuth` — plugs and LiveView hooks
- `Accounts` context — all account operations
- `Scope` — wraps current account for every request

**Hooks available:**
```elixir
{ItWhistWeb.AccountAuth, :mount_current_scope}   # loads user, no redirect
{ItWhistWeb.AccountAuth, :require_authenticated}  # redirects to login if not logged in
{ItWhistWeb.AccountAuth, :require_admin}          # redirects if not admin
```

**Access current user in LiveView:**
```elixir
socket.assigns.current_scope.account.id
socket.assigns.current_scope.account.email
socket.assigns.current_scope.account.is_admin
```

## 5. Ecto Patterns

### Migration
```elixir
def change do
  create table(:things) do
    add :name, :string, null: false
    add :other_id, references(:others, on_delete: :delete_all), null: false
    timestamps(type: :utc_datetime)
  end
  create index(:things, [:other_id])
  create unique_index(:things, [:other_id, :name])
end
```

### Composite PK (no surrogate id)
```elixir
create table(:round_scores, primary_key: false) do
  add :round_id, references(:rounds), null: false, primary_key: true
  add :game_player_id, references(:game_players), null: false, primary_key: true
end
```

### Schema
```elixir
schema "things" do
  field :name, :string
  belongs_to :other, Other           # adds other_id FK
  has_many :children, Child
  timestamps(type: :utc_datetime)
end
```

### Changeset
```elixir
def changeset(thing, attrs) do
  thing
  |> cast(attrs, [:name, :other_id])
  |> validate_required([:name, :other_id])
  |> validate_inclusion(:name, @valid_names)
  |> validate_length(:name, min: 2, max: 60)
  |> foreign_key_constraint(:other_id)
  |> unique_constraint([:other_id, :name])
end
```

### Composite PK schema
```elixir
@primary_key false
schema "round_scores" do
  belongs_to :round, Round, primary_key: true
  belongs_to :game_player, GamePlayer, primary_key: true
  field :score, :integer
end
```

## 10. Key Elixir Concepts Used

**Pattern matching on function args:**
```elixir
def create_game(%Scope{} = scope, attrs) do
  # scope is guaranteed to be a Scope struct
end
```

**Pipe operator:**
```elixir
game
|> Game.changeset(attrs)
|> Repo.update()
```

**With for chaining operations that might fail:**
```elixir
with {:ok, game} <- Repo.insert(game_changeset),
     {:ok, player} <- Repo.insert(player_changeset) do
  {:ok, game}
end
```

**Pin operator in Ecto queries:**
```elixir
game_id = game.id
Repo.all(from gp in GamePlayer, where: gp.game_id == ^game_id)
#                                                          ^ pins external variable
```

**Map.put and Map.merge:**
```elixir
Map.put(attrs, :game_id, game.id)          # add one key
Map.merge(attrs, %{game_id: game.id,       # merge multiple keys
                   round_number: 1})
```
